# 🖼️ Gallery App

A modern and responsive **React Image Gallery** that fetches and displays images using an external API in a clean and visually appealing grid layout.

🔗 **Live Project:**  
https://vaghelashailesh21.github.io/Gallery/

---

## ✨ Features

- Fetches images from an external API  
- Dynamic image loading  
- Responsive grid layout  
- Clean and minimal UI  
- Smooth user experience  

---

## 🛠 Built With

- React JS  
- Vite  
- Tailwind CSS  
- REST API integration
